# Flip-Flops in Digital Electronics

This folder contains Verilog implementations of various types of flip-flops used in sequential digital circuits. Flip-flops are basic memory elements capable of storing one bit of information and are fundamental in the design of counters, registers, and memory systems.

## 📋 List of Flip-Flops Included:

1. **D Flip-Flop (Data or Delay Flip-Flop)**  
   Stores the value of the input 'D' at the moment of a clock edge and holds it until the next clock event.

2. **T Flip-Flop (Toggle Flip-Flop)**  
   Toggles its output state on each clock pulse if the input 'T' is high.

3. **SR Flip-Flop (Set-Reset Flip-Flop)**  
   Has two inputs, 'S' (Set) and 'R' (Reset). It can set or reset the output based on the input combination.

4. **JK Flip-Flop**  
   A universal flip-flop overcoming the invalid state issue of the SR flip-flop. When both inputs are high, it toggles the output.
